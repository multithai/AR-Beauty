# ✨ AR Beauty Filter

AR Beauty Filter ทำงานแบบเรียลไทม์ในเบราว์เซอร์ — **หน้าเนียน ลบสิว** และ **ปรับแต่งหน้าได้** (ตาโต / หน้าเรียว / ผิวขาว / ความสว่าง / โทนสีปาก)

> สร้างด้วย **MediaPipe FaceMesh** (ตรวจจับจุดบนใบหน้า 468 จุด) + **WebGL shader** (ประมวลผลภาพ) — ทุกอย่างรันในเครื่องคุณ ไม่มีการส่งภาพออกไปยังเซิร์ฟเวอร์

## ฟีเจอร์

| ฟีเจอร์ | คำอธิบาย |
|---------|----------|
| 🧴 หน้าเนียน / ลบสิว | Edit-preserving smoothing (bilateral) เฉพาะบริเวณผิวหน้า ตา/ปาก/พื้นหลังยังคมชัด |
| 🤍 ผิวกระจ่างใส | ปรับโทนผิวให้ขาวใสขึ้น |
| ☀️ ความสว่าง | เพิ่มความสว่างเฉพาะใบหน้า |
| 💎 หน้าเรียว | บีบแก้มเข้าหากึ่งกลาง (geometric warp) |
| 👁️ ตาโต | ขยายดวงตาทั้งสองข้าง |
| 💋 โทนสีปาก | เพิ่มสีปากให้สดใส |
| 🎚️ Presets | เนียนธรรมชาติ / ผิวเนียนมาก / สวยจัดเต็ม |
| 👁️ เทียบก่อน/หลัง | กดค้างเพื่อดูภาพต้นฉบับ |
| 📸 ถ่ายรูป | บันทึกภาพที่แต่งแล้วเป็น PNG |
| 🔄 สลับกล้อง | หน้า / หลัง |

## วิธีรัน

ต้องเปิดผ่าน **http/https** (กล้องใช้งานไม่ได้ถ้าเปิดไฟล์ตรง ๆ)

```bash
# วิธีที่ 1
npm start
# แล้วเปิด http://localhost:8080

# วิธีที่ 2 (Python)
python3 -m http.server 8080
```

> 📱 บนมือถือต้องเป็น **HTTPS** เบราว์เซอร์ถึงจะอนุญาตให้ใช้กล้อง (เช่น deploy ขึ้น GitHub Pages / Netlify / Vercel)

## โครงสร้างไฟล์

```
index.html   — หน้าเว็บ + UI
style.css    — สไตล์
app.js       — กล้อง + FaceMesh + WebGL beauty shader
```

## เกี่ยวกับ Banuba Beauty AR SDK

โจทย์อ้างอิงถึง [Banuba Beauty AR SDK](https://www.banuba.com/facear-sdk/beauty-ar)
ซึ่งเป็น **SDK เชิงพาณิชย์ (เสียเงิน / ต้องขอ license key)** ให้คุณภาพระดับโปรดักชัน
(makeup ละเอียด, 3D try-on, reshape หลายแบบ)

โปรเจกต์นี้คือ **เวอร์ชัน open-source ฟรี** ที่ทำหัวใจหลักของ Beauty AR
ได้เหมือนกัน (skin smoothing, retouch, reshape) โดยไม่ต้องเสียค่า license
ถ้าต้องการคุณภาพ/ฟีเจอร์ระดับ Banuba สามารถต่อยอดด้วย SDK จริงได้ภายหลัง

## หมายเหตุทางเทคนิค

- Skin smoothing ใช้ bilateral blur (16-tap) ที่รักษาขอบ จึงไม่เบลอตา/ปาก
- บริเวณที่ปรับจำกัดด้วย elliptical face mask จาก bounding box ของ landmarks
- การปรับรูปหน้า (ตาโต/หน้าเรียว) ทำด้วย geometric warp ใน fragment shader
